# Time Signature

## Definition

The time signature is the pair of stacked numbers at the start of a piece, after the clef: the top number says how many beats each measure holds, the bottom number says which note value counts as one beat.

## Why it matters

It's the first thing a score declares about time, and the drills display one on every exercise. The depth required here is modest: read the two numbers, know what each controls, and don't confuse the stack with the chord figures that appear later in harmony.

## Prerequisites

[[Beat and Measure]] (what is being counted) and the [[Clef]] (its neighbour at the start of the staff).

## Explanation

Read **4/4** as: *four beats per measure; the quarter note gets the beat*. Count "1 2 3 4" and start over at each bar line. In **3/4** you count "1 2 3" — the waltz feel. The scores this app renders all use 4/4, so that count of four is the one you will actually meet; 3/4 is shown here as the standard contrast.

The bottom number is a code for a note value, not a fraction's denominator: 4 = quarter note, 2 = half note, 8 = eighth note. So 4/4 and 3/4 share a beat *length* and differ only in grouping. Faster notes still fit inside — a beat can be subdivided (two eighths, four sixteenths) without changing the signature, which is exactly what the technique drills do.

The time signature is printed once at the start (unlike the clef, it isn't reprinted on every line) and holds until a new one appears.

## In the Lab

Every rendered score carries its time signature. The technique drills give it real work: their figures pack four sixteenth notes into each beat, measure after measure, so the signature's grid is what you're racing — cleanly, evenly, in count.

## Common confusions

- **6/4 the meter vs. 6/4 the chord.** Later in harmony you'll meet "6/4" as a *figured-bass* label for an inverted chord. Same two digits, unrelated meaning — the meter version lives at the staff's start; the chord version hangs on a specific note in an analysis.
- **The bottom number isn't "out of".** 3/4 is not "three quarters of a measure" — it's *three* beats, each a *quarter note* long. The stack is two independent answers, not a fraction.
