# Pitch Class

## Definition

A pitch class is the family of all notes sharing one name across every octave: "pitch class C" means every C on the piano at once. There are twelve pitch classes — one per key inside a single octave.

## Why it matters

This is literally how the app hears you. The grader reduces every note you play to its pitch class, so understanding the idea explains two everyday experiences: you may answer in any octave, and either enharmonic spelling of a note counts as correct.

## Prerequisites

[[Octave]] (the distance being ignored) and [[Enharmonic Equivalence]] (the spellings being merged).

## Explanation

Take the whole keyboard and fold it up like a measuring tape, one [[Octave]] per fold, so that every C lands on every other C. What remains is a loop of just **twelve** positions — the twelve keys of one octave, now standing for all their copies. Each position is a pitch class.

Two merges happen in that fold:

- **Octaves merge.** C3, C4, C5 … are all pitch class C.
- **Spellings merge.** F♯ and G♭ were already the same key, so they were always one pitch class with two names.

Twelve classes, arranged in a loop — you can picture them like numbers on a clock face. That clock picture returns throughout this vault whenever "distance between notes" matters.

## In the Lab

Everywhere. When a drill asks for a C major [[Triad|triad]], the grader checks that the pitch classes C, E, and G are sounding — in whichever octaves your hands chose, under whichever spelling the score used. This is a deliberate kindness *and* a limit worth knowing: the grader will not object if you play a chord in an unusual register, even where the score suggests one.

## Common confusions

- **Pitch class ≠ pitch.** A pitch is one exact note (C4); a pitch class is the whole family (every C). The class forgets the octave on purpose.
- **Pitch class ≠ letter name.** There are seven letters but twelve pitch classes — the classes include the sharp/flat notes, and one class can carry two letter-based names (F♯/G♭).
