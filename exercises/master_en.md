# The hierarchy of tonality

The entire system builds upon itself:

**interval → chord → scale → key → tonality**

---

The following system table shows the **hierarchy of tonal harmony**. The logic builds downward:

**interval → chord → harmonic function → cadence (resolution pattern)**

This is the structure that governs the functioning of classical tonality (Bach–Mozart–Beethoven), as well as much of jazz harmony.

---

# 1. Interval → Chord quality

| Interval structure        | Triad type | Example |
| ------------------------- | ---------- | ------- |
| major third + minor third | major      | C–E–G   |
| minor third + major third | minor      | D–F–A   |
| minor third + minor third | diminished | B–D–F   |
| major third + major third | augmented  | C–E–G#  |

The triad therefore consists of **two stacked thirds**.

---

| Degree | Chord | Function                       |

| vii°   | B°    | dominant-relative              |

# 3. The role of harmonic functions

| Function         | Tension | Role              |
| ---------------- | ------- | ----------------- |
| Tonic (T)        | stable  | resting point     |
| Subdominant (S)  | rising  | departure         |
| Dominant (D)     | maximum | demands resolution |

This is the **dynamic arc of tonality**.

| Level   | Effect              |
| ------- | ------------------- |
| third   | chord quality       |
| fifth   | stability           |
| tritone | tension             |
| tonic   | gravitational center |

The **tritone** found in the dominant creates the strongest tension.

The **B–F tritone** resolves:

    ↓

    ↓

    ↓

The following system table shows the **physical–acoustic foundation** of tonality. Tonality is not entirely arbitrary: the human ear naturally perceives certain ratios of the **harmonic series (overtone series)** as stable. From these, the interval system develops, then chords, and finally tonal harmony.

---

# 1. Harmonic series → Intervals

When a note sounds (for example **C**), not only the fundamental frequency sounds, but also its multiples.

| Overtone | Frequency ratio | Note          | Interval from fundamental |

| 1        | 1:1             | C             | unison                    |
| 2        | 2:1             | C             | octave                    |
| 3        | 3:2             | G             | perfect fifth             |
| 4        | 4:3             | C             | octave                    |
| 5        | 5:4             | E             | major third               |
| 6        | 6:5             | G             | fifth                     |
| 7        | 7:4             | Bb (approx.)  | minor seventh             |
| 8        | 8:1             | C             | octave                    |

The first few overtones therefore already produce:

**C – G – E**

# 2. Harmonic series → Triad

If we take the first stable overtones:

| Overtone | Note |
| -------- | ---- |
| 1        | C    |
| 3        | G    |
| 5        | E    |

Arranged:

**C – E – G**

This is exactly the **C major triad**.

This is why we perceive the major chord as **very stable**.

# 6. The cause of dominant tension

The **tritone** appears in the dominant chord.

Example in C major:

G7 = G B D F

The critical interval:

**B – F**

This is a **tritone**.

Resolution:

| note | resolution |
| ---- | ---------- |
| B    | C          |
| F    | E          |

This is why the dominant pulls back to the tonic.
