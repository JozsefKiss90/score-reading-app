# A 12 moll hangnem

Minden dúr hangnemnek van egy **relatív moll párja** (ugyanaz a hangkészlet, más tonika):

| Dúr | Moll |
| --- | ---- |
| C   | A    |
| G   | E    |
| D   | B    |
| A   | F#   |
| E   | C#   |
| B   | G#   |
| F#  | D#   |
| C#  | A#   |
| F   | D    |
| Bb  | G    |
| Eb  | C    |
| Ab  | F    |

A **moll diatonikus akkordminta** (természetes moll):

**i – ii° – III – iv – v – VI – VII**

---

Rendben — a dúr mintát követve elkészítettem a **12 moll hangnem diatonikus akkordjainak teljes tábláját**.

Fontos: itt a **természetes moll (aeol)** rendszert használjuk, ezért:

* v = **moll domináns**
* VII = **nem vezetőhangos (nem °)**
  (Ha harmonikus moll lenne, akkor V dúr és vii° lenne.)

A hangközök (intervallumok) rendszere a tonalitás egyik alaprétege: ezek határozzák meg a **skálák szerkezetét**, az **akkordok minőségét**, és a **harmóniai feszültséget**. Az alábbi táblák lépésről lépésre rendszerezik a teljes intervallumrendszert.

# A tonalitás hierarchiája

Az egész rendszer egymásra épül:

**intervallum → akkord → skála → hangnem → tonalitás**

---

Az alábbi rendszertábla a **tonális harmónia hierarchiáját** mutatja meg. A logika lefelé épül:

**intervallum → akkord → harmóniai funkció → kadencia (feloldási mintázat)**

Ez az a struktúra, amely a klasszikus tonalitás (Bach–Mozart–Beethoven), de a jazz harmónia nagy részének működését is meghatározza.

---

# 1. Intervallum → Akkord minőség

| Intervallum szerkezet | Triád típusa | Példa  |
| --------------------- | ------------ | ------ |
| nagy terc + kis terc  | dúr          | C–E–G  |
| kis terc + nagy terc  | moll         | D–F–A  |
| kis terc + kis terc   | szűkített    | B–D–F  |
| nagy terc + nagy terc | bővített     | C–E–G# |

A triád tehát **két egymásra épített tercből áll**.

---

# 2. Akkord → Harmóniai funkció (dúr hangnemben)

| Fok  | Akkord | Funkció                         |
| ---- | ------ | ------------------------------- |
| I    | C      | tonika (T)                      |
| ii   | Dm     | pre-domináns / szubdomináns (S) |
| iii  | Em     | tonika-paralel                  |
| IV   | F      | szubdomináns (S)                |
| V    | G      | domináns (D)                    |
| vi   | Am     | tonika-paralel                  |
| vii° | B°     | domináns-paralel                |

---

# 3. Harmóniai funkciók szerepe

| Funkció          | Feszültség | Szerep            |
| ---------------- | ---------- | ----------------- |
| Tonika (T)       | stabil     | nyugalmi pont     |
| Szubdomináns (S) | növekvő    | elmozdulás        |
| Domináns (D)     | maximális  | feloldást követel |

Ez a tonalitás **dinamikai íve**.

---

# 4. Funkció → Kadencia

| Kadencia    | Akkordmenet | Jelentés            |
| ----------- | ----------- | ------------------- |
| autentikus  | V → I       | legerősebb feloldás |
| félkadencia | I → V       | nyitott vég         |
| plagális    | IV → I      | lágy feloldás       |
| deceptív    | V → vi      | váratlan feloldás   |

---

# 5. A teljes tonális lánc

| Szint       | Példa C-dúrban  |
| ----------- | --------------- |
| intervallum | G–B = nagy terc |
| akkord      | G–B–D = G-dúr   |
| funkció     | domináns        |
| kadencia    | G → C           |

---

# 6. A tonalitás gravitációs modellje

| Szint    | Hatás               |
| -------- | ------------------- |
| terc     | akkord minősége     |
| kvint    | stabilitás          |
| tritonus | feszültség          |
| tonika   | gravitációs központ |

A dominánsban található **tritonus** hozza létre a legerősebb feszültséget.

Példa:

G7:

G–B–D–F

A **B–F tritonus** oldódik:

B → C
F → E

→ **C-dúr**

---

# 7. A teljes rendszer egy sorban

| Intervallum | Akkord       | Funkció    | Kadencia    |
| ----------- | ------------ | ---------- | ----------- |
| terc        | triád        | tonika     | stabil      |
| kvart/kvint | szubdomináns | mozgás     | előkészítés |
| tritonus    | domináns     | feszültség | feloldás    |

---

# 8. A tonalitás alap progressziója

A legtöbb klasszikus harmónia erre épül:

**T → S → D → T**

Példa C-dúrban:

C → F → G → C

---

# 9. A jazz univerzális változata

A jazz ezt finomítja:

**ii → V → I**

Példa:

Dm → G → C

---

# 10. A tonalitás „mély képlete”

A rendszer végső formája:

```
intervallum
    ↓
akkord
    ↓
harmóniai funkció
    ↓
kadencia
```

---

Az alábbi rendszertábla a tonalitás **fizikai–akusztikai alapját** mutatja meg. A tonalitás nem teljesen önkényes: az emberi fül a **felhangsor (harmonic series)** bizonyos arányait természetesen stabilnak érzékeli. Ezekből alakul ki az intervallumrendszer, majd az akkordok és végül a tonális harmónia.

---

# 1. Felhangsor → Intervallumok

Ha megszólal egy hang (például **C**), akkor nem csak az alapfrekvencia szól, hanem annak többszörösei is.

| Felhang | Frekvencia arány | Hang          | Intervallum az alaphanghoz |
| ------- | ---------------- | ------------- | -------------------------- |
| 1       | 1:1              | C             | prím                       |
| 2       | 2:1              | C             | oktáv                      |
| 3       | 3:2              | G             | tiszta kvint               |
| 4       | 4:3              | C             | oktáv                      |
| 5       | 5:4              | E             | nagy terc                  |
| 6       | 6:5              | G             | kvint                      |
| 7       | 7:4              | Bb (közelítő) | kis szeptim                |
| 8       | 8:1              | C             | oktáv                      |

Az első néhány felhang tehát már kiadja:

**C – G – E**

---

# 2. Felhangsor → Triád

Ha az első stabil felhangokat vesszük:

| Felhang | Hang |
| ------- | ---- |
| 1       | C    |
| 3       | G    |
| 5       | E    |

Rendezve:

**C – E – G**

Ez pontosan a **C-dúr triád**.

Ezért érzékeljük a dúr akkordot **nagyon stabilnak**.

---

# 3. Intervallum stabilitási hierarchia

| Intervallum | Felhang arány | Stabilitás            |
| ----------- | ------------- | --------------------- |
| oktáv       | 2:1           | maximális             |
| kvint       | 3:2           | nagyon stabil         |
| kvart       | 4:3           | stabil                |
| terc        | 5:4           | mérsékelten stabil    |
| szext       | 5:3           | mérsékelten stabil    |
| szekund     | 9:8           | instabil              |
| szeptim     | 15:8          | nagyon instabil       |
| tritonus    | ~√2           | legerősebb feszültség |

---

# 4. Intervallum → Akkord

| Intervallum szerkezet | Akkord     |
| --------------------- | ---------- |
| nagy terc + kis terc  | dúr triád  |
| kis terc + nagy terc  | moll triád |
| kis terc + kis terc   | szűkített  |
| nagy terc + nagy terc | bővített   |

---

# 5. Akkord → Funkció

A tonalitás három fő funkciót hoz létre.

| Funkció      | Akkordok |
| ------------ | -------- |
| tonika       | I, vi    |
| szubdomináns | ii, IV   |
| domináns     | V, vii°  |

---

# 6. Domináns feszültség oka

Domináns akkordban jelenik meg a **tritonus**.

Példa C-dúrban:

G7 = G B D F

A kritikus intervallum:

**B – F**

Ez **tritonus**.

Feloldása:

| hang | feloldás |
| ---- | -------- |
| B    | C        |
| F    | E        |

Ezért húz vissza a domináns a tonikára.

---

# 7. Kadenciák rendszere

| Kadencia    | Akkordmenet | Funkció    |
| ----------- | ----------- | ---------- |
| autentikus  | V → I       | legerősebb |
| plagális    | IV → I      | lágy       |
| félkadencia | → V         | nyitott    |
| deceptív    | V → vi      | elkerülés  |

---

# 8. A teljes tonális hierarchia

| Szint       | Példa       |
| ----------- | ----------- |
| fizika      | felhangsor  |
| intervallum | kvint, terc |
| akkord      | C–E–G       |
| funkció     | domináns    |
| kadencia    | V–I         |

---

# 9. A tonalitás gravitációs modellje

A rendszer így működik:

```
felhangsor
     ↓
intervallum stabilitás
     ↓
akkordok
     ↓
harmóniai funkció
     ↓
kadencia
     ↓
tonális gravitáció
```

---

# 10. A tonalitás alapprogressziója

A legtöbb klasszikus zene erre a ciklusra épül:

**T → S → D → T**

Példa C-dúrban:

C → F → G → C

---

✅ Ez az a **mély elméleti keret**, amely összeköti:

* a fizikát
* az intervallumrendszert
* az akkordokat
* a funkcionális harmóniát

egy egységes modellben.

# A kvintkör mint térkép

```text
              C
        F           G
     Bb               D
   Eb                   A
     Ab               E
        Db         B
            Gb/F#
```

Minden lépés:

**+1 kvint → +1 kereszt**

ellenkező irány:

**−1 kvint → +1 bé**
