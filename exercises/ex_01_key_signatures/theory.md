# Lecke 1.1 – Hangnemek, hangközök és a kvintkör alapjai

Ez a tananyag a zeneelmélet és a kottaolvasás alapjait vezeti be.
A cél nem a memorizálás, hanem a hangnemi gondolkodás kialakítása,
amely minden későbbi olvasási és gyakorlati feladat alapja lesz.

---

## 1. Mi az a hangnem?

A hangnem egy olyan hangkészlet, amely egy adott alaphang (tonika)
köré szerveződik.

A hangnem meghatározza:

| Szempont | Jelentés |
|--------|---------|
| Hangkészlet | Mely hangok fordulhatnak elő |
| Előjegyzés | Milyen ♯ és ♭ szerepelnek |
| Karakter | dúr vagy moll |
| Stabilitás | mely hangok nyugalmi pontok |

A kottaolvasás nem hangonként történik, hanem mindig
hangnemi összefüggésben.

---

## 2. Dúr hangnemek

A dúr hangnemek világos, stabil karakterűek.
Minden dúr skála ugyanarra a lépésmintára épül.

### Dúr skála – lépésmintázat

egész – egész – fél – egész – egész – egész – fél

### Példa: C-dúr skála

Hangok sorrendben:

C – D – E – F – G – A – B – C

### Skálafokok C-dúrban

| Fok | Hang | Funkció |
|---|---|---|
| I | C | tonika |
| II | D | |
| III | E | |
| IV | F | |
| V | G | domináns |
| VI | A | |
| VII | B | |
| I | C | |

Előjegyzés: nincs

---

## 3. Moll hangnemek (természetes moll)

Ebben a leckében kizárólag a természetes moll skálát használjuk.

### Természetes moll – lépésmintázat

egész – fél – egész – egész – fél – egész – egész

### Példa: a-moll skála

Hangok sorrendben:

A – B – C – D – E – F – G – A

### Beépített félhangog

| Lépés     | Távolság | Miért                  |
| --------- | -------- | ---------------------- |
| C → D     | egész    | van köztük C#          |
| D → E     | egész    | van köztük D#          |
| **E → F** | **fél**  | nincs fekete billentyű |
| F → G     | egész    | van F#                 |
| G → A     | egész    | van G#                 |
| A → B     | egész    | van A#                 |
| **B → C** | **fél**  | nincs fekete billentyű |

### Mit jelent az egész és a fél hang KONKRÉTAN?

- félhang: két szomszédos billentyű a zongorán
- egész hang: két félhang egymás után

Fontos:
- E–F és B–C között természetes félhang van
- minden más természetes hang között egész hang


### Skálafokok a-mollban

| Fok | Hang |
|---|---|
| I | A |
| II | B |
| ♭III | C |
| IV | D |
| V | E |
| ♭VI | F |
| ♭VII | G |
| I | A |

Megjegyzés:
- nincs előjegyzés
- a-moll a C-dúr relatív mollja

---

## 4. Hangközök alapjai

A hangköz két hang közötti távolság.
A hangközök mindig skálán belül értelmezendők.

### Alapvető hangközök

| Hangköz | Példa | Hangszám |
|-------|------|---------|
| szekund | C → D | 2 |
| terc | C → E | 3 |
| kvart | C → F | 4 |
| kvint | C → G | 5 |
| oktáv | C → C | 8 |

### Hangközök C-dúrban (példák)

C → D = nagy szekund  
C → E = nagy terc  
C → G = tiszta kvint  
C → C = tiszta oktáv  

A hangnem határozza meg, hogy egy hangköz nagy, kicsi vagy tiszta.

---

## 5. Előjegyzések szerepe

Az előjegyzések nem kivételek, hanem a hangnem részei.

| Jel | Hatás |
|---|---|
| ♯ | fél hanggal emel |
| ♭ | fél hanggal süllyeszt |

Ha egy hang előjegyzett:
- minden előfordulásra érvényes
- csak a hangnemváltás törli

---

## 6. A kvintkör logikája

A kvintkör a hangnemeket tiszta kvintek szerint rendezi el.

### Dúr hangnemek – kvintkör irányok

Jobbra haladva (keresztek):

C → G → D → A → E

Balra haladva (bék):

C → F → Bb → Eb → Ab

### Kvintkör szabály összefoglalva

| Irány | Változás |
|---|---|
| jobbra | +1 ♯ |
| balra | +1 ♭ |

---

## 7. Relatív dúr és moll hangnemek

Minden dúr hangnemhez tartozik egy relatív moll,
amely ugyanazokat a hangokat használja.

| Dúr | Moll |
|---|---|
| C-dúr | a-moll |
| G-dúr | e-moll |
| D-dúr | h-moll |
| F-dúr | d-moll |

Szabály:
a relatív moll a dúr VI. foka.

---


## 8. Mit kell MOST tudnod ebből?

Ebben a tananyagban a cél:

- felismerni a tonikát
- észrevenni az előjegyzést
- hangnemként olvasni, nem hangonként

A következő tananyagban a kvintkört már
gyakorlati felismerésre és összehasonlításra használjuk.

### Hogyan találod meg az alaphangot (tonikát)?

Ne érzésből dolgozz. Kövesd ezt a sorrendet:

1. Nézd meg az utolsó hangot.
2. Ez lesz az alaphang.
3. Ellenőrzés:
   - az utolsó előtti hang fél hangra van tőle? ✔
4. Csak ezután nevezd meg a hangnemet.
