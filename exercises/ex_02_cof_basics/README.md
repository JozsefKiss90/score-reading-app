# Gyakorlat 1.2 – Kvintkör a gyakorlatban (azonos motívum, más hangnem)

## Cél
Ebben a gyakorlatban azt tanulod meg, hogy:
- ugyanaz a dallami minta hogyan változik,
- amikor a kvintkörben jobbra (♯) vagy balra (♭) lépsz,
- és hogyan kell ezt **kottaolvasás közben azonnal felismerni**.

A feladat lényege nem a dallam megtanulása,
hanem a **hangnemi eltérés észlelése**.

## Alapelv
Minden task:
- ugyanarra a lépésmintára épül,
- csak a hangnem változik,
- **nincs alkalmi módosítójel** (allow_accidentals = false),
- minden módosítás a kulcselőjegyzésből fakad.

## Kvintkör irányok emlékeztető
- C → G → D → A : jobbra, egyre több ♯
- C → F → Bb → Eb : balra, egyre több ♭

## Hogyan gyakorolj?
Minden tasknál:
1. Azonosítsd a hangnemet.
2. Nevezd meg magadban: hány ♯ vagy ♭ van.
3. Olvasd le a dallamot lassan.
4. Figyeld meg: **mely hang változott az előző taskhoz képest**.

## Ellenőrző kérdések
- Mi az egyetlen (vagy kevés) hang, ami eltér?
- Merre léptünk a kvintkörben?
- Dúr vagy moll érzetű lett a dallam?
